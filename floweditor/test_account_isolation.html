Flow Editor Account Isolation Test

Test Purpose

This test verifies that flows are properly isolated between different accounts. Each account should maintain its own flow data in localStorage.

Test Steps

  1. Open the Flow Editor for Account 1 and Account 2 below
  2. Create or modify a flow in Account 1
  3. Create or modify a different flow in Account 2
  4. Refresh both frames - each should maintain its own flow data
  5. Check browser console for account-specific storage keys (flow_1, flow_2)
