Complete Account Isolation Test

Test Overview

This test verifies that the Flow Editor properly isolates data between different accounts:

  • Each account should have its own localStorage namespace
  • Flows saved in one account should not be visible in another
  • Account-specific fallback loading should work correctly
  • Cross-account data contamination should be prevented
